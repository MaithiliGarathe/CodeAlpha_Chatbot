# 🤖 Chatbot

A simple Python-based chatbot developed as part of the **CodeAlpha Python Programming Internship**.

The chatbot interacts with users through a command-line interface and responds to basic user messages.

## 🚀 Features

- 💬 Interactive conversation
- 👋 Responds to greetings
- ❓ Handles basic questions
- 🔄 Continuous conversation until exit
- 🖥️ Simple command-line interface
- 🐍 Built using Python

## 🛠️ Technologies Used

- Python
- Conditional statements
- Functions
- Loops
- Strings
- User input
